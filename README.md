# Sabiha Tabassum - Portfolio Website

A modern and responsive personal portfolio website built to showcase my skills, projects, experience, certifications, and frontend development journey.

## 🚀 Live Demo

(https://saba-sabiha-portfolio.vercel.app/)

## 📌 Features

- ✨ Modern responsive UI design
- 📱 Fully responsive for mobile, tablet, and desktop
- 🎨 Beautiful gradient-based design
- 🧭 Smooth navigation between sections
- 📄 Resume download/view option
- 💼 Projects showcase
- 🛠️ Skills section
- 🏆 Certifications section
- 💡 Experience and insights sections
- 📩 Contact section
- ⚡ Fast performance with Vite

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript (ES6+)
- Tailwind CSS
- HTML5
- CSS3

### Tools
- Vite
- Git & GitHub
- VS Code
